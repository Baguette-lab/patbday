SAINT'S BIRTHDAY WEBSITE — VS CODE FILES

Unzip and open this folder in Visual Studio Code. Open index.html in a browser or use the Live Server extension. Keep all nine files together. No build or internet connection is required.

BACKGROUND MUSIC
- The small floating music player stays visible on every tab. It attempts to play a gentle bundled track when the site opens and loops it. If your browser blocks sound until interaction, one tap on the page or the player starts it. The button pauses or resumes the track.
- To make YOUR song play for every visitor: rename your MP3 file background-music.mp3 and replace the file with that exact name in this folder. Then publish the updated website folder to your host. Keep the filename in index.html unchanged. MP3 works in modern browsers.
- The gear icon has a song picker to preview an audio file on your own device during this visit. A song chosen through that picker is local to your browser visit; it does not change the hosted song for other people.
- A volume slider is available in music settings. When the birthday candle is blown out, background music pauses for the separate birthday melody and resumes when that song ends or the scene closes.

OTHER FEATURES
The eight Birthday Bureau trials unlock the other tabs. The human photo puzzle uses birthday-puzzle-photo.jpg. The Quiet Corner candle opens a 2D celebration for Pat with three independent animated sprites and a short instrumental birthday melody (birthday-song.mp3). The friends can be tapped for extra reactions.

To edit the pop-up greeting, search index.html for celebrationTitle. To edit the birthday message, search for letterPaper.
